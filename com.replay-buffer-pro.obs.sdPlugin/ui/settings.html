How to connect OBS
  1. Install the Replay Buffer Pro OBS plugin and enable the replay buffer in OBS (Settings → Output → Replay Buffer).
  2. In OBS open Tools → WebSocket Server Settings and tick Enable WebSocket server.
  3. Click Show Connect Info and copy the port and password here.

No OBS hotkeys are needed: the keys run Replay Buffer Pro's save actions directly.
