How to set up chibisafe
  1. Enter your chibisafe server URL. In chibisafe open Dashboard → Credentials and copy your API key here.
  2. Optional: pick an Album to collect your clips in (↻ reloads the list).
  3. Tick Upload saved clips and copy the link. Each save key can opt out, or pick its own album, in its own settings.

OBS must run on this computer, because the plugin uploads the clip from disk. MP4 clips play in the browser; MKV links usually download instead.

How to connect OBS
  1. Install the Replay Buffer Pro OBS plugin (1.8.0 or newer) and enable the replay buffer in OBS (Settings → Output → Replay Buffer).
  2. In OBS open Tools → WebSocket Server Settings and tick Enable WebSocket server.
  3. Click Show Connect Info and copy the port and password here.

No OBS hotkeys are needed: the keys ask Replay Buffer Pro to save directly. A key longer than your replay buffer saves the whole buffer.

When OBS isn't running, the On/Off key shows NO OBS; pressing it opens OBS. Set OBS app only if OBS isn't found by itself, e.g. a portable install: the path to obs64.exe, or OBS.app on a Mac.
