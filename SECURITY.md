# Security policy

## Supported versions

Only the [latest release](https://github.com/jerptrs/streamdeck-replay-buffer-pro/releases/latest) receives
security fixes. Please check that the problem still happens there before reporting it.

## Reporting a vulnerability

Please don't report security issues in public issues, pull requests or discussions.

Report them privately through GitHub instead: open the repository's **Security** tab and choose
[Report a vulnerability](https://github.com/jerptrs/streamdeck-replay-buffer-pro/security/advisories/new).

Please include:

- the plugin version, your operating system, and your Stream Deck, OBS and Replay Buffer Pro versions
- what the problem is and what an attacker could do with it
- steps to reproduce it, or a proof of concept
- a suggested fix, if you have one

You'll get a reply in the report as soon as possible. Confirmed issues are fixed in a new release and disclosed
in a security advisory afterwards, with credit to you unless you'd rather stay anonymous.

## Scope

This policy covers the plugin in this repository: for example its connection to OBS, the chibisafe uploads, the
handling of your OBS password and chibisafe API key, and the files it reads.

Vulnerabilities in other software belong with those projects:
[OBS Studio](https://github.com/obsproject/obs-studio),
[Replay Buffer Pro](https://github.com/JoshuaPotter/replay-buffer-pro),
[chibisafe](https://github.com/chibisafe/chibisafe), and the Stream Deck app ([Elgato](https://help.elgato.com)).
